# Obiwan Kendogu

A Star Wars-themed Kendo equipment shop with full cart functionality, dynamic discounts, and a humorous checkout experience.

[**Live Demo**](https://obiwan-kendogu.netlify.app/)

## Features

- Dynamic inventory rendering from JavaScript data array
- Add/remove items from cart with quantity controls
- 15% discount when all 4 items are added to cart
- Mock checkout process with payment modal
- Interactive star rating with themed feedback messages

## Built with

JavaScript, HTML, CSS

## How it works

- Inventory stored in JavaScript array and rendered dynamically
- Event listeners track cart additions/removals and update totals in real-time
- Discount automatically applies when cart contains all inventory items
- Modal form captures payment details and displays confirmation
- Star rating system with hover effects and click-to-select functionality
